> **"Speak Confidently Wherever You Go."**  
> Travel Phrasebook is a production-quality, full-stack web application designed for global travelers. Powered by **Google Gemini AI** and native browser **Web Speech Synthesis**, it generates contextually accurate native phrases, phonetic pronunciation guides, cultural etiquette tips, business protocols, and emergency SOS tools.

---

## 🌟 Key Features

- 🤖 **Contextual AI Phrasebook Generation**: Generates 8–12 highly realistic phrases per situation scenario tailored for specific destinations and languages using Gemini AI (`gemini-2.5-flash`).
- 🔊 **Native Text-To-Speech (TTS)**: Built-in audio controls (Play, Stop, Replay, Speaking animation state) with dual speed modes (🐢 **Slow 0.6x** vs ▶ **Normal 0.9x**).
- 🗣 **Highly Visible Pronunciation**: Displays native script (Kanji/Kana, Devanagari, Arabic, Tamil, etc.), Latin phonetic guides, English meanings, and etiquette tips.
- 💬 **Ask AI for a Phrase**: Custom AI query input (e.g. *"I want to ask the hotel for late checkout"*) returning native translation, formal & casual variations, and usage tips.
- 🇮🇳 **Deep Support for Indian Regional Languages**: Comprehensive phrasebooks and regional hub for 9 major Indian languages: **Hindi, Gujarati, Marathi, Bengali, Tamil, Telugu, Kannada, Malayalam, Punjabi**.
- 🚨 **24/7 Offline Emergency SOS Mode (`/emergency`)**: High-visibility SOS cards (*"I need help"*, *"Call an ambulance"*, *"I lost my passport"*) with direct local helpline numbers (**India: 112**, **Japan: 110/119**, **EU: 112**, **USA: 911**).
- 💼 **Corporate Business Etiquette (`/business`)**: 8 corporate categories (*Meeting, Greetings, Business Cards, Negotiation, etc.*), formal vs. casual comparisons, business tips, and corporate taboos.
- 🧠 **Interactive Spaced-Repetition Quiz (`/quiz`)**: Dynamic 5–10 question quizzes generated by Gemini with score tracking, accuracy percentage, performance ratings (🏆 *Excellent*, 🔥 *Great Job*, 👍 *Good*, 📚 *Keep Practicing*), and local storage history.
- ❤️ **Favorites Persistence (`/favorites`)**: Bookmark phrases with `localStorage` persistence across sessions.
- 📊 **Traveler Learning Dashboard (`/dashboard`)**: Track learning progress, accuracy bars, completed quiz attempts, and saved trips.
- 🧳 **AI Personalization & Difficulty Options**: Personalize phrase generation by Traveller Persona (*Solo, Family, Business, Student*) and Difficulty Level (*Beginner, Intermediate, Advanced*).

## 🔒 Security & Gemini Integration Architecture

- **Zero Key Exposure**: The `GEMINI_API_KEY` is loaded exclusively inside server-side Next.js API Routes (`app/api/*`). It is **never exposed** in client JavaScript bundles or browser network requests.
- **Input Validation**: Request bodies are validated on the server for required fields (`destination`, `language`, `situation`, `query`).
- **Resilient Fallback Mode**: If `GEMINI_API_KEY` is unconfigured or rate-limited, the application seamlessly serves curated native phrase fallback data so the UI remains 100% functional without breaking or showing raw technical stack traces.

## ⚙️ Environment Variables

Create a file named `.env.local` in the project root:

```env
# Google Gemini API Key
GEMINI_API_KEY=your_actual_gemini_api_key_here
```

### How to get a Gemini API Key:
1. Visit [Google AI Studio](https://aistudio.google.com/).
2. Sign in with your Google account.
3. Click **"Create API Key"**.
4. Copy the generated API key and paste it into `.env.local` as `GEMINI_API_KEY`.

## 🚀 Quickstart & Local Development

### 1. Prerequisites
- **Node.js**: v18.17.0 or higher
- **npm**: v9.0.0 or higher

### 2. Installation
Clone the repository and install dependencies:

```bash
git clone https://github.com/your-username/travel-phrasebook.git
cd travel-phrasebook
npm install
```

### 3. Run Development Server
Start the local Next.js server with Turbopack:

```bash
npm run dev
```

Open your browser and navigate to:
[http://localhost:3000](http://localhost:3000)

### 4. Build for Production
To test TypeScript compilation and generate static production bundles:

```bash
npm run build
npm run start
```
